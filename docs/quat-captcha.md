# Project Charter — UETCO

## 1. Project name
UETCO — Unified Environment for Theories and Creative Output

## 2. Purpose
To create a modern educational platform that supports structured subject, module, and file management with a true admin CRUD environment and a secure verification layer.

## 3. Problem
The previous version relied on static HTML pages and GitHub-hosted file access. It lacked real management capability, secure access control, and scalable architecture.

## 4. Goals
- modern UI and experience
- robust admin CRUD interface
- built-in verification layer
- Vercel-friendly deployment structure
- future-ready extension to database-backed storage

## 5. Scope
### In scope
- landing page
- subject browsing
- module browsing
- file browsing
- admin login
- admin dashboard
- CRUD routes for subject/module/file records
- QUAT CAPTCHA support

### Out of scope
- full SaaS multi-tenant architecture in phase 1
- AI features beyond core product foundation

## 6. Unique feature
Structured academic catalog management with strong admin controls and a human verification layer that preserves the QUAT CAPTCHA concept.

## 7. Technical stack
- Next.js 14
- TypeScript
- React
- App Router
- JSON API store

## 8. Deliverables
- project source code
- modern UI
- CRUD-enabled admin environment
- docs and project charter
- Vercel-ready app structure

## 9. Success criteria
- admin can create and manage content
- system remains responsive and modern
- footer is preserved as required
- QUAT CAPTCHA remains active
- app deploys cleanly on Vercel
